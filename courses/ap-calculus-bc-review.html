How to Get a 5 on This Exam

📊 What the Exam Tests Most

AP Calc BC covers everything in AP Calc AB (limits, derivatives, integrals, FTC, differential equations) plus: integration techniques (by parts, partial fractions), sequences and series (convergence tests, Taylor/Maclaurin series, radius of convergence), parametric equations, polar coordinates, and vector-valued functions. Series is the most heavily weighted BC-only content and historically produces the most student errors.

⚠️ Where Students Lose Points

Students apply the wrong convergence test using the ratio test on a polynomial series (where the limit equals 1, inconclusive) instead of the p-series or comparison test. Students also lose points for not justifying conclusions using the complete test statement. In FRQs, students set up correct integrals but forget to include the constant of integration in antiderivatives or forget to apply initial conditions for differential equations.

🎯 What Separates a 3 from a 5

A 3 student can compute derivatives and basic integrals. A 5 student reasons about series convergence strategically (choosing the appropriate test), understands radius of convergence and its meaning, can write Taylor series from scratch using the formula T(x) = Σ f^(n)(a)/n! (x-a)^n, and can manipulate these series algebraically to find related series.

📅 Final 2 to 3 Weeks Strategy

Create a convergence test decision flowchart: alternating → alternating series test; ratio involving factorials → ratio test; p-series form → p-series; geometric → geometric series; otherwise → comparison or limit comparison. Practice writing Taylor series for e^x, sin x, cos x, 1/(1-x) from memory. Do parametric and polar area/arc length problems. Do 2 full FRQ sets per week.

Exam-Day Skills

  • Series convergence strategy: First check if the limit of terms → 0 (if not, diverges by divergence test). Then identify series type. For series with (-1)^n, try alternating series test. For series with n! or a^n, try ratio test. For series of the form 1/n^p, use p-series.
  • Taylor series error bound: For alternating series, the error is ≤ the absolute value of the first omitted term. Know how to use this to determine how many terms are needed for a given accuracy.
  • Integration by parts: Use LIATE to choose u: Logarithms, Inverse trig, Algebraic, Trig, Exponential. ∫u dv = uv − ∫v du. Sometimes requires applying IBP twice (tabular method for repeated applications).
  • FRQ differential equations: For slope fields, verify the DE at given points. For separation of variables, always include +C, apply initial condition to solve for C, and write the explicit solution.
  • Parametric and polar: dy/dx = (dy/dt)/(dx/dt). Polar area = ½∫r² dθ. Arc length = ∫√((dx/dt)² + (dy/dt)²) dt. Know these formulas and when to apply them.

📋 How FRQ Scoring Works

Section I (50%): Part A: 30 MCQs without calculator (60 min); Part B: 15 MCQs with calculator (45 min). Section II (50%): Part A: 2 FRQs with calculator (30 min); Part B: 4 FRQs without calculator (60 min).

FRQ scoring (~9 pts each): Each FRQ is multi-part. Parts include: finding derivatives or antiderivatives, setting up and evaluating integrals, analyzing function behavior, solving differential equations, working with series convergence and Taylor polynomials, or analyzing parametric/polar curves.

Work requirements: Show all steps. An answer without supporting work earns 1 pt at most (the answer point). Integration steps, differentiation steps, and algebraic manipulation must be shown. Including +C for indefinite integrals is required for that point.

Differential equations: For separation of variables: clearly separate variables, integrate both sides (including +C), apply initial condition to find C, write explicit solution. Each step earns a point independently.

Series: For convergence/divergence problems, always state the test used, show that the test conditions are met, and state the conclusion. 'By the ratio test, since lim|a_{n+1}/a_n| = L < 1, the series converges absolutely.'

Follow-through credit: If you make an error in part (a) but correctly use it in part (b) with correct method, you earn part (b) points.

Practice Questions

Multiple Choice (20 Questions)

Q1. The derivative of f(x) = x³ + 4x² - 7x + 2 is:

  • A. 3x² + 4x - 7
  • B. 3x² + 8x - 7
  • C. x² + 8x - 7
  • D. 3x³ + 8x² - 7x
Show Answer

Answer: B: Power rule: d/dx[xⁿ] = nxⁿ⁻¹. d/dx[x³] = 3x², d/dx[4x²] = 8x, d/dx[-7x] = -7, d/dx[2] = 0. Sum: 3x² + 8x - 7.

Q2. The integral ∫(2x + 3)dx is:

  • A. 2x² + 3x
  • B. x² + 3x + C
  • C. 2x + 3 + C
  • D. x² + 3 + C
Show Answer

Answer: B: Antidifferentiation: ∫2x dx = x², ∫3 dx = 3x. Result: x² + 3x + C. Always include +C for indefinite integrals.

Q3. lim(x→0) [sin(x)/x] =

  • A. 0
  • B. 1
  • C. ∞
  • D. undefined
Show Answer

Answer: B: This fundamental limit equals 1. It can be proven geometrically using the squeeze theorem, and is foundational for computing derivatives of trig functions.

Q4. The chain rule states that if y = f(g(x)), then dy/dx =

  • A. f'(x) × g'(x)
  • B. f'(g(x)) × g'(x)
  • C. f'(g(x)) + g'(x)
  • D. f'(g'(x))
Show Answer

Answer: B: Chain rule: differentiate the outer function evaluated at the inner function, multiplied by the derivative of the inner function.

Q5. Which test determines convergence of a series by comparing it to a geometric series?

  • A. Integral test
  • B. Ratio test
  • C. Comparison test
  • D. Alternating series test
Show Answer

Answer: B: The Ratio test: if lim|a(n+1)/a(n)| = L < 1, series converges absolutely; if L > 1, diverges; if L = 1, inconclusive. Particularly useful for series with factorials or exponentials.

Q6. A function f has a critical point at x = c if:

  • A. f(c) = 0
  • B. f'(c) = 0 or f'(c) is undefined
  • C. f''(c) = 0
  • D. f(c) is the largest value in its domain
Show Answer

Answer: B: Critical points occur where the derivative is zero or undefined these are candidates for local maxima, minima, or saddle points.

Q7. The Fundamental Theorem of Calculus Part 1 states that if F(x) = ∫(a to x) f(t)dt, then:

  • A. F(x) = f(x)
  • B. F'(x) = f(x)
  • C. F(x) = f'(x)
  • D. F'(x) = f'(x)
Show Answer

Answer: B: FTC Part 1: the derivative of the accumulation function equals the integrand at the upper limit. d/dx[∫(a to x) f(t)dt] = f(x).

Q8. The Taylor series for e^x centered at x = 0 is:

  • A. 1 + x + x²/2 + x³/6 + ...
  • B. 1 + x + x² + x³ + ...
  • C. x + x²/2! + x³/3! + ...
  • D. 1 - x + x²/2! - x³/3! + ...
Show Answer

Answer: A: The Maclaurin series for e^x = Σ(n=0 to ∞) xⁿ/n! = 1 + x + x²/2! + x³/3! + ... = 1 + x + x²/2 + x³/6 + ...

Q9. L'Hôpital's Rule applies when evaluating limits of the form:

  • A. 0/1 or 1/0
  • B. 0/0 or ∞/∞ (indeterminate forms)
  • C. Any fraction
  • D. Only polynomial functions
Show Answer

Answer: B: L'Hôpital's Rule: if lim[f(x)/g(x)] gives 0/0 or ∞/∞, then lim[f(x)/g(x)] = lim[f'(x)/g'(x)], provided the latter limit exists.

Q10. The integral ∫₀^π sin(x) dx =

  • A. 0
  • B. 2
  • C. 1
  • D. -1
Show Answer

Answer: B: ∫sin(x)dx = -cos(x) + C. Evaluating: [-cos(x)]₀^π = -cos(π) - (-cos(0)) = -(-1) - (-1) = 1 + 1 = 2.

Q11. A series Σaₙ converges absolutely if:

  • A. Σaₙ converges
  • B. Σ|aₙ| converges
  • C. aₙ → 0
  • D. The ratio test gives L = 1
Show Answer

Answer: B: Absolute convergence: if Σ|aₙ| converges (the series of absolute values converges), then Σaₙ also converges. Absolute convergence is a stronger condition than conditional convergence.

Q12. For parametric equations x = f(t), y = g(t), dy/dx equals:

  • A. g(t)/f(t)
  • B. g'(t)/f'(t)
  • C. f'(t)/g'(t)
  • D. g(t)/f'(t)
Show Answer

Answer: B: Parametric derivative: dy/dx = (dy/dt)/(dx/dt) = g'(t)/f'(t), provided f'(t) ≠ 0.

Q13. The disk method for finding volume when rotating f(x) around the x-axis gives:

  • A. V = π∫[f(x)]dx
  • B. V = π∫[f(x)]²dx
  • C. V = 2π∫x, f(x)dx
  • D. V = ∫2πf(x)dx
Show Answer

Answer: B: Disk method: V = π∫[f(x)]² dx. Slice the solid into thin disks of radius f(x) and thickness dx; volume of each disk = π[f(x)]²dx.

Q14. The error bound for the alternating series Σ(-1)ⁿaₙ (with terms decreasing to zero) is:

  • A. Less than or equal to the first omitted term
  • B. Less than or equal to the sum of the first n terms
  • C. Less than or equal to the last included term
  • D. Exactly zero
Show Answer

Answer: A: Alternating Series Estimation Theorem: the absolute error in using the first n terms of an alternating series (that satisfies AST conditions) is at most the absolute value of the first omitted term |a(n+1)|.

Q15. Euler's method for approximating differential equations uses:

  • A. Exact integration of the differential equation
  • B. Linear approximation at each step, moving along the tangent line to estimate the next point
  • C. Taylor polynomial of degree 2 or higher
  • D. The exact solution evaluated at discrete points
Show Answer

Answer: B: Euler's method: starting at (x₀, y₀), use the slope from the ODE at the current point to take a step: y(n+1) = y(n) + h, f(x(n), y(n)), where h is the step size.

Q16. A polar curve r = f(θ) has area enclosed given by:

  • A. A = ∫f(θ)dθ
  • B. A = ½∫[f(θ)]²dθ
  • C. A = ∫[f(θ)]²dθ
  • D. A = π∫[f(θ)]²dθ
Show Answer

Answer: B: Polar area formula: A = ½∫[r]²dθ = ½∫[f(θ)]²dθ. The factor of ½ comes from the area of a circular sector (A = ½r²Δθ).

Q17. Integration by parts formula is:

  • A. ∫uv dx = u'v' + C
  • B. ∫u dv = uv - ∫v du
  • C. ∫u dv = uv + ∫v du
  • D. ∫uv dx = u∫v dx + C
Show Answer

Answer: B: Integration by parts: ∫u dv = uv - ∫v du. Choose u and dv using LIATE (Logarithm, Inverse trig, Algebraic, Trig, Exponential) to guide which factor becomes u.

Q18. A geometric series Σarⁿ converges if and only if:

  • A. a < 1
  • B. │r│ < 1
  • C. r > 0
  • D. a + r < 2
Show Answer

Answer: B: Geometric series Σ(n=0 to ∞) arⁿ converges to a/(1-r) if and only if |r| < 1 (the common ratio has absolute value less than 1). If |r| ≥ 1, the series diverges.

Q19. The Mean Value Theorem guarantees that for a continuous function on [a,b] differentiable on (a,b):

  • A. f(a) = f(b)
  • B. There exists c in (a,b) where f'(c) = [f(b)-f(a)]/(b-a)
  • C. The function has a maximum on [a,b]
  • D. f'(c) = 0 for some c in (a,b)
Show Answer

Answer: B: MVT: there exists at least one point c in (a,b) where the instantaneous rate of change (f'(c)) equals the average rate of change ([f(b)-f(a)]/(b-a)) over the interval.

Q20. The improper integral ∫(1 to ∞) 1/x² dx equals:

  • A. ∞ (diverges)
  • B. 1
  • C. 2
  • D. 1/2
Show Answer

Answer: B: ∫(1 to ∞) x⁻² dx = [-x⁻¹](1 to ∞) = (0) - (-1) = 1. Compare with ∫(1 to ∞) 1/x dx = ∞ (diverges) the 'boundary' between convergence and divergence for p-series is p = 1.

Free Response Questions

FRQ 1 (FRQ)

Let f(x) = x³ - 6x² + 9x + 1. (a) Find all critical points of f and determine whether each is a local maximum, local minimum, or neither. (b) Find the intervals on which f is concave up and concave down. (c) Find the absolute maximum and minimum of f on the closed interval [0, 4].
View Model Answer
(a) Critical points: f'(x) = 3x² - 12x + 9 = 3(x² - 4x + 3) = 3(x-1)(x-3). Set f'(x) = 0: x = 1 and x = 3. Classify using First or Second Derivative Test: f''(x) = 6x - 12. f''(1) = 6(1) - 12 = -6 < 0 → x = 1 is a local MAXIMUM. f''(3) = 6(3) - 12 = 6 > 0 → x = 3 is a local MINIMUM. Values: f(1) = 1 - 6 + 9 + 1 = 5 (local max). f(3) = 27 - 54 + 27 + 1 = 1 (local min). (b) Concavity: f''(x) = 6x - 12 = 0 at x = 2 (inflection point). For x < 2: f''(x) < 0 → concave DOWN. For x > 2: f''(x) > 0 → concave UP. Inflection point at x = 2: f(2) = 8 - 24 + 18 + 1 = 3, so inflection point is (2, 3). (c) Absolute extrema on [0, 4]: Evaluate f at critical points and endpoints. f(0) = 0 - 0 + 0 + 1 = 1. f(1) = 5 (local max). f(3) = 1 (local min). f(4) = 64 - 96 + 36 + 1 = 5. Absolute MAXIMUM: f = 5 at x = 1 and x = 4. Absolute MINIMUM: f = 1 at x = 0 and x = 3.

FRQ 2 (FRQ)

(a) Write the first four nonzero terms of the Maclaurin series for f(x) = sin(x). (b) Use your series from part (a) to write the first four nonzero terms of the Maclaurin series for g(x) = sin(x²). (c) Use the series from part (b) to approximate ∫₀^(0.5) sin(x²) dx. Explain why your approximation is valid and bound the error.
View Model Answer
(a) Maclaurin series for sin(x): Using the formula f(x) = Σ (-1)ⁿ x^(2n+1)/(2n+1)! for n = 0, 1, 2, 3, ...: sin(x) = x - x³/3! + x⁵/5! - x⁷/7! + ... = x - x³/6 + x⁵/120 - x⁷/5040 + ... (b) Substitute x² for x in the sin(x) series: sin(x²) = x² - (x²)³/6 + (x²)⁵/120 - (x²)⁷/5040 + ... = x² - x⁶/6 + x¹⁰/120 - x¹⁴/5040 + ... (c) Approximating the integral: ∫₀^(0.5) sin(x²) dx ≈ ∫₀^(0.5) [x² - x⁶/6 + x¹⁰/120] dx (using first three terms). = [x³/3 - x⁷/42 + x¹¹/1320]₀^(0.5) = (0.5)³/3 - (0.5)⁷/42 + (0.5)¹¹/1320 = 0.125/3 - 0.0078125/42 + 0.00048828/1320 = 0.04167 - 0.000186 + 0.00000037 ≈ 0.04148. The series for sin(x²) converges for all x (infinite radius of convergence), and the integral of sin(x²) from 0 to 0.5 can be approximated using the Alternating Series Estimation Theorem since the integrated series is alternating with decreasing terms. The error is at most the first omitted term: |∫₀^(0.5) x¹⁴/5040 dx| = [(0.5)¹⁵/(5040×15)] ≈ 2×10⁻⁹ negligible.

FRQ 3 (FRQ)

A particle moves along the x-axis. Its velocity at time t is v(t) = t² - 4t + 3 for 0 ≤ t ≤ 4. (a) Find all times t in [0, 4] when the particle is at rest. (b) Find the total distance traveled by the particle on [0, 4]. (c) Find the position of the particle at t = 4 if its initial position is x(0) = 2.
View Model Answer
(a) Particle at rest when v(t) = 0: t² - 4t + 3 = 0 → (t-1)(t-3) = 0 → t = 1 and t = 3. Both are in [0, 4]. (b) Total distance: must integrate |v(t)| (distance, not displacement). Check sign of v(t) in each interval: [0,1]: test t=0.5: (0.25-2+3)=1.25 > 0 (moving right). [1,3]: test t=2: (4-8+3)=-1 < 0 (moving left). [3,4]: test t=3.5: (12.25-14+3)=1.25 > 0 (moving right). Total distance = ∫₀¹ v(t)dt + |∫₁³ v(t)dt| + ∫₃⁴ v(t)dt. ∫v(t)dt = t³/3 - 2t² + 3t + C. [t³/3 - 2t² + 3t]₀¹ = (1/3 - 2 + 3) - 0 = 4/3. [t³/3 - 2t² + 3t]₁³ = (9 - 18 + 9) - (1/3 - 2 + 3) = 0 - 4/3 = -4/3, so |displacement| = 4/3. [t³/3 - 2t² + 3t]₃⁴ = (64/3 - 32 + 12) - (9 - 18 + 9) = (64/3 - 20) - 0 = 4/3. Total distance = 4/3 + 4/3 + 4/3 = 4. (c) Position at t = 4: x(t) = x(0) + ∫₀⁴ v(t)dt. Net displacement = [t³/3 - 2t² + 3t]₀⁴ = (64/3 - 32 + 12) - 0 = 64/3 - 20 = 4/3. x(4) = 2 + 4/3 = 10/3 ≈ 3.33.
