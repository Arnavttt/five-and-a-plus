How to Get a 5 on This Exam

📊 What the Exam Tests Most

AP CSP tests creative development, data, algorithms and programming (pseudocode), computing systems and networks, impact of computing, and cybersecurity. The Create Performance Task (30% of score) requires you to write and document a program with an algorithm involving sequencing, selection, and iteration. The exam pseudocode is AP-specific you must know the College Board pseudocode syntax, not Python or Java syntax.

⚠️ Where Students Lose Points

Students lose Create Task points by not clearly identifying the 'student-developed procedure' in their video and written responses. The procedure must include a parameter that affects functionality and must contain sequencing, selection, AND iteration all three. Students also confuse the definition of 'algorithm' (a finite set of instructions) vs. 'procedure' (a named group of programming instructions).

🎯 What Separates a 3 from a 5

A 3 student completes the Create Task but writes minimal documentation. A 5 student writes documentation that clearly explains HOW the algorithm works (not just WHAT it does), identifies WHY specific design choices were made, and addresses potential limitations with intellectual honesty. The written response quality is the primary differentiator.

📅 Final 2 to 3 Weeks Strategy

Review all Create Task written response prompts practice writing 3b (algorithm description), 3c (testing with two different calls), and 3d (data abstraction). Memorize College Board pseudocode syntax (DISPLAY, INPUT, IF/ELSE/END IF, REPEAT n TIMES, REPEAT UNTIL, FOR EACH). Study internet protocols (TCP/IP, DNS, HTTP) and cybersecurity concepts for the multiple choice exam.

Exam-Day Skills

  • Create Task 3b: Your algorithm description must explain the algorithm step-by-step and explicitly mention sequencing, selection (conditional), and iteration (loop). Don't describe what the code does explain HOW the algorithm achieves the result.
  • Create Task 3c testing: Show two calls where the result is DIFFERENT (not just different inputs with the same type of output). One call should test a typical case; one should test an edge case or boundary condition.
  • AP pseudocode: Know APPEND(list, value), INSERT(list, i, value), REMOVE(list, i), LENGTH(list). Use ← for assignment. Use [] for list literals. Know MOD (modulo operator).
  • Binary and data: Know how to convert binary to decimal and vice versa. Know that n bits can represent 2^n values. Understand lossless vs. lossy compression and their trade-offs.
  • MCQ elimination: For 'which of the following is true about the Internet' questions, eliminate answers that suggest centralized control the Internet is deliberately designed to be decentralized and fault-tolerant.

📋 How FRQ Scoring Works

Section I (70%): 70 MCQs in 120 min. Section II (30%): Create Performance Task: submitted beforehand (not during the exam).

Create Performance Task scoring (not done on exam day):
• Program Purpose and Development (2 pts): Written responses explaining the program's purpose and development process. Must be specific: not just 'I made a game' but explaining design decisions and testing approach.
• Algorithm and Program Code (3 pts): Identify a student-developed procedure with sequencing, selection, AND iteration. Written response explains HOW the algorithm works (not just what it does). Show two calls with different results in the program video.
• Abstraction (2 pts): Identify a list (or other collection) and explain how the program stores data in the list AND uses the list to manage complexity.

MCQ Section: Tests computing concepts (binary, compression, protocols), algorithm analysis (time complexity, correctness), data analysis (interpreting visualizations), and impacts of computing (privacy, security, economic effects). Know AP pseudocode syntax precisely: all algorithm questions use it.

Common MCQ traps: Questions about 'which program is equivalent' require careful logic tracing. Questions about undecidable problems require knowing the halting problem concept.

Practice Questions

Multiple Choice (20 Questions)

Q1. Which of the following is NOT a valid binary representation of the decimal number 13?

  • A. 00001101
  • B. 00001100
  • C. 0000000000001101
  • D. 11111111111110011 (two's complement)
Show Answer

Answer: B: 13 in binary = 8+4+1 = 00001101. 00001100 = 12, not 13.

Q2. The Internet protocol suite uses which addressing system to uniquely identify devices?

  • A. MAC addresses only
  • B. IP addresses (IPv4: 32-bit; IPv6: 128-bit) assigned hierarchically to route packets
  • C. URL addresses
  • D. Port numbers alone
Show Answer

Answer: B: IP addresses uniquely identify network interfaces. IPv4 uses 32-bit addresses (e.g., 192.168.1.1); IPv6 uses 128-bit to accommodate the exhaustion of IPv4 space.

Q3. A 'bug' in a program caused by unexpected input that crashes the system is most likely:

  • A. A logic error
  • B. A runtime error correct syntax but unexpected behavior when executed with certain inputs
  • C. A compilation error
  • D. A semantic error
Show Answer

Answer: B: Runtime errors occur during execution division by zero, null pointer access, out-of-bounds array access often triggered by unexpected input even when code compiles and runs correctly with normal input.

Q4. Lossless compression differs from lossy compression in that:

  • A. Lossless is always smaller
  • B. Lossless allows perfect reconstruction of the original data; lossy discards some information to achieve higher compression ratios
  • C. Lossless is used only for images
  • D. Lossy compression is illegal
Show Answer

Answer: B: Lossless (ZIP, PNG, FLAC): original data perfectly reconstructed. Lossy (JPEG, MP3): irreversible data reduction; acceptable when small quality loss is acceptable for much smaller file size.

Q5. The concept of 'abstraction' in computing refers to:

  • A. Making programs run faster
  • B. Managing complexity by hiding implementation details and exposing only necessary functionality through well-defined interfaces
  • C. Compressing data
  • D. Translating high-level code to machine code
Show Answer

Answer: B: Abstraction is fundamental to CS: functions, objects, APIs, and operating systems all hide complexity behind simple interfaces. A programmer using sort() doesn't need to know the sorting algorithm's implementation.

Q6. Which of the following best describes a 'phishing' attack?

  • A. Exploiting a vulnerability in software code
  • B. Deceiving users into revealing sensitive information by masquerading as a trusted entity
  • C. Installing malware without user interaction
  • D. Overwhelming a server with traffic
Show Answer

Answer: B: Phishing: social engineering attack where attackers impersonate legitimate entities (banks, employers) via email, messages, or fake websites to steal credentials, financial information, or install malware.

Q7. The term 'cloud computing' refers to:

  • A. Computing performed in underground data centers
  • B. Delivering computing resources (storage, processing, software) over the Internet on a pay-per-use basis
  • C. Weather-related computing applications
  • D. Wireless network computing
Show Answer

Answer: B: Cloud computing delivers on-demand computing resources via the Internet: IaaS (infrastructure), PaaS (platforms), SaaS (software). Examples: AWS, Azure, Google Cloud, Dropbox, Gmail.

Q8. Net neutrality refers to the principle that:

  • A. All Internet traffic must use the same encryption
  • B. Internet service providers must treat all Internet traffic equally, regardless of source, destination, or content
  • C. The Internet should have equal access globally
  • D. Net speeds must be equal for all users
Show Answer

Answer: B: Net neutrality: ISPs cannot discriminate by slowing down, blocking, or charging more for certain websites/services. Repealed in the US in 2017; its status remains contested.

Q9. A sorting algorithm with O(n²) time complexity is significantly worse than O(n log n) because:

  • A. O(n²) uses more memory
  • B. For large n, n² grows much faster than n log n doubling n quadruples O(n²) operations but only slightly more than doubles O(n log n)
  • C. O(n²) algorithms cannot be parallelized
  • D. O(n log n) algorithms have no worst case
Show Answer

Answer: B: For n = 1,000: O(n²) = 1,000,000 operations; O(n log n) ≈ 10,000 operations. For n = 1,000,000: O(n²) = 10¹², O(n log n) ≈ 20,000,000 a factor of 50,000 difference.

Q10. Which of the following is an example of 'crowdsourcing'?

  • A. A company using its own employees to test software
  • B. Wikipedia's collaborative editing by millions of volunteers worldwide
  • C. A government database collecting citizen information
  • D. A program that learns from its own outputs
Show Answer

Answer: B: Crowdsourcing: distributing tasks to a large group of people (the 'crowd'), often via the Internet. Wikipedia, Waze traffic reporting, citizen science projects, and Amazon Mechanical Turk are examples.

Q11. The 'digital divide' refers to:

  • A. The difference between analog and digital signals
  • B. Unequal access to digital technologies based on factors including income, geography, age, and disability
  • C. The gap between hardware and software development
  • D. The distinction between data and information
Show Answer

Answer: B: Digital divide: socioeconomic, geographic, and demographic disparities in access to computers, Internet, and digital literacy perpetuating existing inequalities by excluding communities from economic and educational opportunities requiring digital access.

Q12. Public-key (asymmetric) cryptography uses:

  • A. The same secret key for encryption and decryption
  • B. A mathematically linked pair a public key to encrypt and a private key to decrypt enabling secure communication without sharing a secret key in advance
  • C. A one-time pad for each message
  • D. Physical delivery of encryption keys
Show Answer

Answer: B: Asymmetric cryptography (RSA, ECC): anyone can encrypt with the public key; only the private key holder can decrypt. Enables HTTPS, digital signatures, and secure key exchange over untrusted networks.

Q13. Metadata associated with a digital file includes:

  • A. The actual content of the file (text, pixels, audio)
  • B. Information about the file: creation date, file size, location, author, device used often collected and stored without users' explicit awareness
  • C. The file's encryption key
  • D. The file's backup copies
Show Answer

Answer: B: Metadata is data about data. Photo metadata (EXIF) includes GPS coordinates, camera model, timestamp. Document metadata includes author, revision history. Metadata can reveal sensitive information even when content is encrypted.

Q14. A 'distributed denial of service' (DDoS) attack works by:

  • A. Stealing user credentials through phishing
  • B. Overwhelming a server with traffic from many compromised machines simultaneously, making the service unavailable to legitimate users
  • C. Installing ransomware on a server
  • D. Exploiting a buffer overflow vulnerability
Show Answer

Answer: B: DDoS: attackers use botnets (networks of compromised computers) to flood targets with traffic exceeding their capacity, disrupting service. The distributed nature makes it difficult to block by IP address.

Q15. Which of the following demonstrates a 'creative commons' licensing approach?

  • A. Copyright: all rights reserved, no reuse without permission
  • B. A license allowing others to share, adapt, or build upon work with attribution, making knowledge freely accessible
  • C. A patent protecting a manufacturing process
  • D. Trade secret protection of proprietary algorithms
Show Answer

Answer: B: Creative Commons licenses enable creators to share work with specified permissions attribution, commercial use, derivative works enabling open knowledge sharing while preserving certain creator rights.

Q16. In the context of machine learning, 'training data bias' means:

  • A. The algorithm runs faster on biased data
  • B. When training data systematically underrepresents or misrepresents certain groups, causing the model to produce discriminatory outputs
  • C. Training takes too long
  • D. The model is too simple to learn patterns
Show Answer

Answer: B: Algorithmic bias: facial recognition systems trained predominantly on white male faces have higher error rates for women and people of color. Hiring algorithms trained on historical data perpetuate historical discrimination. Biased input produces biased output.

Q17. The Internet's packet-switching architecture is significant because:

  • A. It requires a dedicated connection between sender and receiver
  • B. Data is broken into packets that can take different routes, making the network resilient to node failures
  • C. It is faster than circuit-switching for all uses
  • D. It requires central coordination to route all packets
Show Answer

Answer: B: Packet switching: data is divided into packets that independently route through the network and reassemble at the destination. Any path can be used if one router fails, packets route around it. This distributed resilience was explicitly designed for military communications survivability.

Q18. Which of the following is an example of 'citizen science'?

  • A. Scientists performing peer-reviewed research
  • B. Volunteers collecting environmental data, classifying galaxies, or analyzing protein folding using distributed computing (SETI@home, Foldit, eBird)
  • C. Government-funded scientific research
  • D. Science education in public schools
Show Answer

Answer: B: Citizen science: non-professional volunteers contribute to scientific research collecting data, analyzing images, or providing computing power. Enables research at scales impossible for small professional teams.

Q19. A 'feedback loop' in a complex system occurs when:

  • A. Output of a process has no effect on future inputs
  • B. The output of a process influences future inputs to that same process, potentially amplifying (positive) or dampening (negative) change
  • C. Two systems exchange data
  • D. A program calls itself recursively
Show Answer

Answer: B: Feedback loops: negative (stabilizing) feedback dampens change (thermostat); positive (amplifying) feedback accelerates change (microphone near speaker creates squeal). Complex systems exhibit both types, producing emergent, sometimes unpredictable behavior.

Q20. Data encryption is important for protecting privacy because:

  • A. It prevents data from being collected
  • B. It ensures that even if data is intercepted or stolen, it cannot be read without the decryption key
  • C. It makes data transmission faster
  • D. It verifies the identity of the sender
Show Answer

Answer: B: Encryption scrambles data so that only parties with the correct key can read it protecting data in transit (HTTPS) and at rest (encrypted hard drives). Without encryption, intercepted data is immediately readable.

Free Response Questions

FRQ 1 (FRQ)

a) Define an algorithm and explain the difference between an efficient algorithm and an inefficient one using Big-O notation. b) The following pseudocode searches a sorted list: FOR i FROM 0 TO length(list)-1: IF list[i] = target THEN RETURN i RETURN -1 Explain why this is inefficient for large sorted lists and describe a more efficient algorithm. c) Explain ONE real-world consequence of algorithm efficiency for society.
View Model Answer
a) An algorithm is a finite, unambiguous sequence of steps that solves a problem or accomplishes a task. Big-O notation describes how an algorithm's time or space requirements grow as input size n increases. An efficient algorithm has a growth rate that remains manageable for large inputs O(log n) or O(n log n) are efficient; O(n²) or O(2^n) are inefficient. For n = 1,000,000: O(log n) ≈ 20 operations; O(n) = 1,000,000; O(n²) = 10¹² a factor of 10⁶ difference that makes some problems tractable and others practically unsolvable. b) The pseudocode implements linear search: O(n). It checks every element from the beginning, potentially examining the entire list before finding the target or confirming it's absent. For a sorted list of 1,000,000 elements, this could require up to 1,000,000 comparisons. A more efficient algorithm is binary search: O(log n). Binary search exploits the sorted order: compare target to the middle element; if target is less, eliminate the right half; if greater, eliminate the left half; repeat. For 1,000,000 elements, at most log₂(1,000,000) ≈ 20 comparisons are needed a 50,000x improvement. c) Search engine indexing: Google's search algorithms must retrieve relevant results from billions of pages in milliseconds. If Google used O(n²) algorithms, each search would require impractical computation. Efficient algorithms (inverted indices, PageRank) enable real-time search at web scale. Inefficient algorithms for genome sequencing would make personalized medicine computationally impossible efficient algorithms for sequence alignment (like Smith-Waterman) made genomics practical. Algorithmic efficiency determines what problems are solvable in reasonable time and therefore what technologies are possible.

FRQ 2 (FRQ)

The collection and use of personal data by technology companies raises ethical questions. a) Describe TWO ways that companies collect personal data from users. b) Explain ONE benefit and ONE harm of large-scale personal data collection. c) Explain the concept of 'informed consent' in data privacy and describe ONE challenge to achieving genuine informed consent in modern digital services.
View Model Answer
a) Method 1: Behavioral tracking: Companies track user behavior on their platforms through cookies (small data files stored in browsers), pixel trackers embedded in emails and web pages, and server-side logging of every click, search, page view, and purchase. This data is often collected continuously, across sessions and devices, and shared with third-party data brokers who aggregate it with data from other sources to build detailed behavioral profiles. Method 2: Data from connected devices (IoT): Smart speakers (Amazon Echo, Google Home) continuously listen for wake words and collect voice recordings. Smart TVs track viewing habits. Fitness trackers collect biometric data (heart rate, sleep patterns, location). Smartphone apps request permissions for location, contacts, camera, and microphone, often collecting data beyond what users expect from the app's stated function. b) Benefit: Personalized recommendations improve user experience and efficiency. Netflix's recommendation algorithm helps users find content they'll enjoy from a catalog of thousands of titles; Spotify's Discover Weekly surfaces music users wouldn't find manually. Medical data collection enables disease surveillance (COVID-19 tracking) and research that improves treatment outcomes. Harm: Surveillance capitalism enables manipulation. Detailed behavioral profiles allow platforms to target political advertising with unprecedented precision, potentially manipulating voting behavior. Insurance companies or employers with access to health data could discriminate against individuals with certain conditions. The Cambridge Analytica scandal demonstrated how harvested social media data could be used for targeted political manipulation at scale. c) Informed consent requires that users: (1) know what data is collected, (2) understand how it will be used, (3) voluntarily agree without coercion, and (4) have the ability to refuse without losing essential services. Challenge: Terms of service agreements the legal mechanism for consent are typically thousands of words of legal jargon that users cannot practically read or understand. A Carnegie Mellon study estimated it would take 76 work days per year to read all the privacy policies users encounter. Furthermore, refusing consent often means being excluded from services that have become essential infrastructure (Google, social media, smartphone platforms), making consent effectively non-voluntary. Dark patterns in UI design manipulate users toward accepting data collection. Real informed consent is structurally undermined by the business model that makes free services possible.

FRQ 3 (FRQ)

a) Explain what the Internet's Domain Name System (DNS) does and why it is important. b) Explain how HTTPS protects data transmitted between a browser and a web server. c) Describe ONE vulnerability in Internet security and explain how it can be mitigated.
View Model Answer
a) DNS (Domain Name System) translates human-readable domain names (www.google.com) into numerical IP addresses (142.250.80.4) that computers use to route packets. Without DNS, users would need to memorize IP addresses for every site. DNS works hierarchically: a recursive resolver queries root nameservers, then top-level domain (TLD) servers (.com, .org), then authoritative nameservers for the specific domain, caching results to speed future lookups. DNS is critical infrastructure DNS failures or attacks can make large portions of the Internet unreachable (the 2016 Dyn DDoS attack disrupted Twitter, Netflix, Reddit by targeting their DNS provider). b) HTTPS protection: HTTPS (HTTP Secure) combines HTTP with TLS (Transport Layer Security) encryption. When a browser connects to an HTTPS site: (1) The server presents a digital certificate (signed by a trusted Certificate Authority) proving its identity. (2) Browser and server perform a TLS handshake, using asymmetric cryptography to securely exchange a session key. (3) All subsequent communication is encrypted with symmetric encryption using that session key making intercepted data unreadable without the key. HTTPS protects against: eavesdropping (ISPs, governments, attackers on the same network cannot read traffic), man-in-the-middle attacks (forged certificates are detected), and data tampering (modifications are detected). c) Vulnerability: SQL injection attacks occur when user input is inserted directly into database queries without sanitization. A login form vulnerable to SQL injection might execute: SELECT * FROM users WHERE username = '[user_input]' AND password = '[password]'. An attacker who enters username: ' OR '1'='1 causes the query to always return true, bypassing authentication entirely. More destructive injections can delete tables or extract entire databases. Mitigation: Parameterized queries (prepared statements) treat user input as data rather than executable SQL, preventing injection. Input validation rejects inputs that don't match expected formats. Web Application Firewalls detect and block common injection patterns. Regular security audits and penetration testing identify vulnerabilities before attackers do. The OWASP Top 10 security risks (including SQL injection) provides a standard framework for developers to address common vulnerabilities.
