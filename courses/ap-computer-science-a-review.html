How to Get a 5 on This Exam

📊 What the Exam Tests Most

AP CS A tests Java programming with emphasis on object-oriented programming (classes, inheritance, polymorphism, interfaces), arrays and ArrayLists, 2D arrays, recursion, searching/sorting algorithms, and the AP CS A Java Subset. The FRQ section (50% of score) tests: class writing, method implementation, array traversal, 2D array manipulation, and inheriting/extending classes. The exam provides a Quick Reference sheet with String and ArrayList methods.

⚠️ Where Students Lose Points

Students lose points in FRQs by accessing array indices out of bounds (using < arr.length, not <= arr.length). Students forget to cast when dividing integers int/int always returns int in Java (5/2 = 2, not 2.5). Students also lose points by writing methods that don't return a value (missing return statement) or return the wrong type. In inheritance FRQs, students forget to call super() or use super.methodName() appropriately.

🎯 What Separates a 3 from a 5

A 3 student can write basic Java methods. A 5 student writes clean, correct code with proper edge case handling (empty arrays, null checks), uses Java idioms correctly (enhanced for loops when appropriate, Integer.MAX_VALUE for initialization in min-finding), and can trace through recursive code accurately to identify return values for given inputs.

📅 Final 2 to 3 Weeks Strategy

Practice FRQ types daily: write a complete class with constructor and methods (Part A), implement a method that uses a class from Part A (Part B/C). Review ArrayList methods (add, remove, get, set, size). Practice 2D array traversal patterns. Trace through recursive methods by hand. Know when to use for vs. enhanced-for loops (can't use enhanced-for when modifying the collection or needing the index).

Exam-Day Skills

  • Array traversal errors: Standard for loop: for(int i = 0; i < arr.length; i++). Never use ≤. For 2D arrays: outer loop over rows (arr.length), inner loop over columns (arr[0].length).
  • Integer arithmetic: Always cast to double for division: (double)a/b or a/(double)b. Know that Math.random() returns [0.0, 1.0), so (int)(Math.random() * n) gives [0, n-1].
  • Recursion tracing: Write the call stack by hand. For each recursive call, write the argument value and trace what it returns. Work bottom-up from the base case to find the final return value.
  • Inheritance FRQ: When a subclass constructor must call the superclass constructor, the super() call must be the FIRST statement. To call a superclass method that has been overridden, use super.methodName().
  • FRQ scoring: You get credit for correct logic even with minor syntax errors (missing semicolons, typos in method names), but logic errors cost full points. Write the algorithm correctly first, then check syntax.

📋 How FRQ Scoring Works

Section I (50%): 40 MCQs in 90 min. Section II (50%): 4 FRQs in 90 min (~22 min each).

FRQ types and scoring:
• Methods and Control Structures (~9 pts): Write methods using arrays, loops, and conditionals. Graded on: correct logic, correct loop bounds, correct return type, and handling edge cases.
• Class Writing (~9 pts): Write a complete class with instance variables, constructor, and methods. Graded on: correct class structure, appropriate access modifiers, constructor initialization, and method correctness.
• Array/ArrayList (~9 pts): Traverse, search, filter, or modify an array or ArrayList. Graded on: correct traversal bounds, correct modification approach, correct removal (using index decrement when removing in a loop).
• 2D Array (~9 pts): Traverse and process a 2D array (matrix). Graded on: nested loop structure, correct row/column indexing.

Partial credit: Java syntax errors (missing semicolons, wrong capitalization) are penalized only once per exam. Logical errors in one part do NOT prevent credit in other parts. Write the algorithm correctly first, then worry about syntax.

No penalty for extra: Writing extra helpful methods or comments earns no penalty, only potential benefit from showing understanding.

Practice Questions

Multiple Choice (20 Questions)

Q1. In Java, which of the following correctly declares and initializes an integer variable?

  • A. int x;
  • B. int x = 5;
  • C. integer x = 5;
  • D. Int x = 5;
Show Answer

Answer: B: Java integer declaration and initialization: type name = value; → int x = 5; Java is case-sensitive (int not Int) and uses primitive type int (not 'integer').

Q2. What is the output of: int x = 7; System.out.println(x % 3);

  • A. 2
  • B. 1
  • C. 3
  • D. 0
Show Answer

Answer: B: The modulus operator (%) returns the remainder of integer division. 7 / 3 = 2 remainder 1. Therefore 7 % 3 = 1.

Q3. A recursive method MUST have:

  • A. A loop inside it
  • B. A base case that terminates the recursion
  • C. A return type of void
  • D. At least two parameters
Show Answer

Answer: B: Recursion requires a base case (terminating condition) to prevent infinite recursion. Without a base case, the method calls itself indefinitely until a StackOverflowError occurs.

Q4. Which data structure operates on a Last-In-First-Out (LIFO) principle?

  • A. Queue
  • B. Stack
  • C. Array
  • D. LinkedList
Show Answer

Answer: B: A stack operates LIFO: the last element added (pushed) is the first one removed (popped). Used in method call management, undo operations, and expression evaluation.

Q5. What does the following code print? for(int i = 0; i < 3; i++) { System.out.print(i + ' '); }

  • A. 0 1 2
  • B. 1 2 3
  • C. 0 1 2 3
  • D. Error
Show Answer

Answer: A: The loop initializes i=0, runs while i<3, incrementing i each iteration. Prints: 0 (space) 1 (space) 2 (space). The loop terminates when i=3.

Q6. In Java, an interface:

  • A. Is a class that can be instantiated
  • B. Defines a contract of methods that implementing classes must provide
  • C. Can have instance variables
  • D. Can be extended using 'extends' keyword only
Show Answer

Answer: B: A Java interface declares abstract methods (and optionally default/static methods) that any implementing class must provide. Interfaces enable polymorphism without inheritance hierarchy constraints.

Q7. Which sorting algorithm has the best average-case time complexity?

  • A. Bubble sort: O(n²)
  • B. Merge sort or QuickSort: O(n log n)
  • C. Selection sort: O(n²)
  • D. Insertion sort: O(n²)
Show Answer

Answer: B: Merge sort and QuickSort both achieve O(n log n) average-case performance, dramatically faster than O(n²) algorithms for large n. Merge sort is guaranteed O(n log n); QuickSort has O(n²) worst case.

Q8. In Java, the 'inheritance' relationship is established using:

  • A. implements keyword
  • B. extends keyword
  • C. inherits keyword
  • D. super keyword
Show Answer

Answer: B: In Java, a subclass inherits from a superclass using the 'extends' keyword: public class Dog extends Animal. This establishes an is-a relationship, allowing the subclass to inherit methods and fields.

Q9. A NullPointerException in Java occurs when:

  • A. An array index is out of bounds
  • B. You attempt to call a method on a reference variable that holds null (no object)
  • C. Integer division by zero occurs
  • D. A type cast fails
Show Answer

Answer: B: NullPointerException: attempting to use (dereference) a null reference calling a method or accessing a field on an object reference that hasn't been assigned to an actual object.

Q10. What is the output of: int[] arr = {5, 3, 8, 1}; System.out.println(arr.length);

  • A. 3
  • B. 4
  • C. 5
  • D. Error
Show Answer

Answer: B: arr.length returns the number of elements in the array. The array {5, 3, 8, 1} has 4 elements, so arr.length = 4. Note: length is a field (no parentheses), not a method.

Q11. Binary search requires that the array be:

  • A. Sorted in descending order only
  • B. Sorted (in any order, ascending or descending)
  • C. Unsorted
  • D. Filled with integers only
Show Answer

Answer: B: Binary search works by repeatedly halving the search space by comparing the target to the middle element. This only works correctly if the array is sorted otherwise the algorithm cannot determine which half to discard.

Q12. The concept of 'encapsulation' in OOP refers to:

  • A. Using inheritance to share code
  • B. Bundling data (fields) and methods that operate on that data within a class, and restricting direct access to internal state
  • C. Having multiple implementations of the same interface
  • D. Breaking programs into small functions
Show Answer

Answer: B: Encapsulation: hiding an object's internal state by making fields private and providing controlled access through public getter/setter methods. This protects data integrity and enables implementation changes without breaking client code.

Q13. What is the time complexity of accessing an element in an array by index?

  • A. O(n)
  • B. O(1)
  • C. O(log n)
  • D. O(n²)
Show Answer

Answer: B: Array access by index is O(1) constant time the memory address is computed directly as base_address + index × element_size, regardless of array size. This is the fundamental advantage of arrays over linked structures.

Q14. In Java, the 'static' keyword applied to a method means:

  • A. The method cannot be overridden
  • B. The method belongs to the class itself (not instances) and can be called without creating an object
  • C. The method executes faster
  • D. The method can only access static fields
Show Answer

Answer: B: Static methods belong to the class, not instances. They can be called as ClassName.methodName() without instantiating the class. Static methods cannot access instance (non-static) fields or methods directly.

Q15. Which of the following correctly creates an ArrayList of Strings in Java?

  • A. ArrayList list = new ArrayList();
  • B. ArrayList list = new ArrayList();
  • C. List list = new List();
  • D. String[] list = new ArrayList();
Show Answer

Answer: B: Generics syntax: ArrayList name = new ArrayList(); (or new ArrayList<>() with diamond operator in Java 7+). This creates a type-safe list that only accepts String objects.

Q16. A two-dimensional array int[][] grid = new int[3][4] has:

  • A. 3 elements
  • B. 12 elements (3 rows × 4 columns)
  • C. 7 elements
  • D. 4 rows and 3 columns
Show Answer

Answer: B: A 2D array [3][4] has 3 rows and 4 columns, containing 3 × 4 = 12 integer elements total.

Q17. The output of: String s = 'Hello'; System.out.println(s.substring(1, 3)); is:

  • A. Hel
  • B. el
  • C. ell
  • D. He
Show Answer

Answer: B: substring(startIndex, endIndex) returns characters from startIndex (inclusive) to endIndex (exclusive). 'Hello'.substring(1,3): index 1 = 'e', index 2 = 'l', index 3 is excluded. Result: 'el'.

Q18. In Java, the equals() method for objects should be used instead of == because:

  • A. == is not a valid operator in Java
  • B. == checks reference equality (same object in memory), while equals() checks value equality (same content)
  • C. equals() is faster than ==
  • D. == only works for primitive types in all situations
Show Answer

Answer: B: For objects, == checks if two references point to the SAME object in memory. equals() (when properly overridden) checks if objects have the SAME content/value. For String comparison, always use equals().

Q19. What does it mean for an algorithm to be O(n log n)?

  • A. The algorithm makes n times log(n) comparisons per element
  • B. As input size n grows, runtime grows proportional to n × log(n)
  • C. The algorithm uses log(n) memory for each of n elements
  • D. The algorithm runs in constant time
Show Answer

Answer: B: Big-O notation describes asymptotic growth rate. O(n log n) means runtime grows proportional to n × log(n). This is the theoretical lower bound for comparison-based sorting algorithms and is significantly faster than O(n²) for large n.

Q20. The 'polymorphism' concept in OOP allows:

  • A. Multiple inheritance from multiple classes
  • B. The same method call to behave differently depending on the actual object type
  • C. A class to have multiple constructors
  • D. Variables to store values of any type
Show Answer

Answer: B: Polymorphism (many forms): a superclass reference can hold subclass objects, and method calls are resolved at runtime based on the actual object type (dynamic dispatch). Allows writing code against an interface that works with any implementation.

Free Response Questions

FRQ 1 (FRQ)

Consider the following Java class: public class Student { private String name; private int grade; public Student(String name, int grade) { this.name = name; this.grade = grade; } public String getName() { return name; } public int getGrade() { return grade; } } (a) Write a static method findTop that takes an ArrayList and returns the Student with the highest grade. (b) Write a method that returns the average grade of all students in an ArrayList. (c) What is the output if two students have the same highest grade? Explain how you would modify findTop to handle ties.
View Model Answer
(a) findTop method: public static Student findTop(ArrayList students) { if (students == null || students.isEmpty()) return null; Student top = students.get(0); for (int i = 1; i < students.size(); i++) { if (students.get(i).getGrade() > top.getGrade()) { top = students.get(i); } } return top; } This iterates through the list, tracking the student with the maximum grade found so far. (b) Average grade method: public static double averageGrade(ArrayList students) { if (students == null || students.isEmpty()) return 0.0; int total = 0; for (Student s : students) { total += s.getGrade(); } return (double) total / students.size(); } Cast to double before division to avoid integer truncation. (c) If two students have the same highest grade, findTop as written returns the FIRST one encountered (whichever appears earlier in the ArrayList). The method finds the student whose grade strictly exceeds all previously seen grades, so among ties it returns the first tied student. To handle ties by returning all tied students: modify the return type to ArrayList, initialize the list with the first student, and when encountering an equal grade, add to the list; when encountering a higher grade, clear the list and start fresh with the new top student. Return the completed ArrayList of all students tied for the highest grade.

FRQ 2 (FRQ)

Write a Java method that implements binary search on a sorted integer array. (a) Write the complete binarySearch method with signature: public static int binarySearch(int[] arr, int target) (b) Trace the execution of your method with arr = {2, 5, 8, 12, 16, 23, 38, 56, 72, 91} and target = 23. (c) Explain why binary search is more efficient than linear search for large sorted arrays.
View Model Answer
(a) Binary Search implementation: public static int binarySearch(int[] arr, int target) { int low = 0; int high = arr.length - 1; while (low <= high) { int mid = low + (high - low) / 2; // avoids integer overflow if (arr[mid] == target) { return mid; // found target, return index } else if (arr[mid] < target) { low = mid + 1; // target is in right half } else { high = mid - 1; // target is in left half } } return -1; // target not found } (b) Execution trace with arr = {2, 5, 8, 12, 16, 23, 38, 56, 72, 91}, target = 23: Iteration 1: low=0, high=9, mid=4, arr[4]=16. 16 < 23, so low = 5. Iteration 2: low=5, high=9, mid=7, arr[7]=56. 56 > 23, so high = 6. Iteration 3: low=5, high=6, mid=5, arr[5]=23. 23 == 23 → return 5. Result: index 5. The method found 23 in 3 comparisons. (c) Binary search efficiency: Linear search checks elements one by one in the worst case requiring n comparisons (O(n)) for an array of n elements. Binary search halves the search space each iteration: after 1 step, n/2 candidates remain; after 2 steps, n/4; after k steps, n/2^k. The maximum number of comparisons is log₂(n). For n=1,000,000: linear search may need 1,000,000 comparisons; binary search needs at most log₂(1,000,000) ≈ 20 comparisons. For large sorted arrays, this difference (O(n) vs O(log n)) is enormous and makes binary search dramatically faster.

FRQ 3 (FRQ)

(a) Explain the concept of inheritance in Java with a concrete example involving an Animal superclass and Dog subclass. (b) What is method overriding? Write a code example. (c) Explain the difference between overriding and overloading in Java.
View Model Answer
(a) Inheritance allows a subclass to extend a superclass, inheriting its fields and methods: public class Animal { private String name; public Animal(String name) { this.name = name; } public String getName() { return name; } public String makeSound() { return 'Some sound'; } } public class Dog extends Animal { private String breed; public Dog(String name, String breed) { super(name); // calls Animal constructor this.breed = breed; } public String getBreed() { return breed; } } Dog myDog = new Dog('Rex', 'Labrador'); System.out.println(myDog.getName()); // inherited from Animal -> 'Rex' System.out.println(myDog.getBreed()); // Dog-specific -> 'Labrador' Inheritance establishes an is-a relationship: a Dog IS-A Animal. The Dog class inherits getName() from Animal without rewriting it. (b) Method Overriding: A subclass provides its own implementation of a method already defined in the superclass. The @Override annotation confirms the intention: public class Dog extends Animal { // ... (fields and constructor as above) @Override public String makeSound() { return 'Woof!'; } } Animal a = new Dog('Rex', 'Labrador'); System.out.println(a.makeSound()); // Prints 'Woof!' (runtime polymorphism) At runtime, Java uses the actual object type (Dog) to determine which makeSound() to call, even though the reference type is Animal. (c) Overriding vs. Overloading: Overriding: same method name and parameter list as a superclass method, in a subclass, providing a new implementation. Resolved at RUNTIME based on actual object type (dynamic dispatch). Requires inheritance relationship. Overloading: same method name but DIFFERENT parameter list (different number or types of parameters) in the SAME class. Resolved at COMPILE time based on the argument types. No inheritance required. Example of overloading: public int add(int a, int b) { return a + b; } public double add(double a, double b) { return a + b; } // overloaded public int add(int a, int b, int c) { return a + b + c; } // overloaded
