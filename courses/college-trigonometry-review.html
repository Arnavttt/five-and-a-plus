How to Score 100 on College Trigonometry

📊 What the Exam Tests Most

The unit circle, right triangle trig ratios, trig identities, and solving trig equations. Your instructor will test exact values (not just calculator approximations), identity proofs, and graphing transformations.

⚠️ Where Students Lose Points

Forgetting exact values from the unit circle, sign errors in different quadrants (ASTC), and skipping steps in identity proofs. Memorizing the unit circle completely is non-negotiable.

🎯 What Separates a 3 from a 5

Students who score 100 have the unit circle fully memorized, understand identities conceptually (not just memorized), and can work through multi-step problems without losing track of signs.

📅 Final 2 to 3 Weeks Strategy

Drill the unit circle until you can write it from memory in under 2 minutes. Practice one identity proof every day. Re-solve all missed test problems without notes.

Exam-Day Skills

  • Memorize the full unit circle: all 16 angles with exact sin, cos, and tan values
  • ASTC rule: All Students Take Calculus: which functions are positive in each quadrant
  • For identity proofs: always start with the more complex side and simplify
  • For graphing: identify amplitude, period, phase shift, and vertical shift before drawing
  • For solving equations: find the reference angle first, then apply quadrant rules
  • Show all steps in identity proofs: credit is given for each valid step

Essential Concepts

  • Unit circle: coordinates, standard angle values (0°, 30°, 45°, 60°, 90°, and reflections)
  • Graphing sin, cos, tan: period = 2π/B, amplitude = |A|, phase shift = −C/B
  • Fundamental identities: Pythagorean, quotient, reciprocal
  • Sum/difference and double-angle formulas
  • Laws of Sines and Cosines for oblique triangles

Exam Day Tips

✓

Reference angle is always positive and between 0° and 90° use it to evaluate trig in any quadrant.

✓

For graphing: identify A, B, C, D in y = A | sin(Bx − C) + D before sketching.

✓

Inverse trig: arcsin and arccos have restricted domains know them ([−π/2, π/2] and [0, π]).

✓

Polar conversion: x = r | cos θ, y = r | sin θ, r² = x² + y².

Final Reminder: Review each unit's must-know section, then come back here to check your vocabulary and concepts. Good luck: you've got this! 🎯

📋 How Free Response Scoring Works

Section I: Multiple choice covering the unit circle, trig equations, identities, and triangle applications. Section II: Free-response requiring work shown for trig equations, identity proofs, and law of sines/cosines applications.

Scoring principles:
• Trig equation scoring: Every solution within the specified interval must be found: missing one solution loses that point. For general solutions, correctly expressing the pattern (+ 2πn or + πn) earns the general solution point.
• Identity proof scoring: Work must show clear progression from one side to the final form. Each algebraic step earns credit if correct. Do NOT work on both sides simultaneously: work on one side only.
• Triangle application scoring: For ambiguous case (SSA) problems: you must check whether 0, 1, or 2 triangles are possible by comparing given side to the altitude (h = b sin A). Failing to check for the ambiguous case loses points.
• Polar and complex numbers: Show conversion steps (r = √(x²+y²), θ = arctan(y/x)) explicitly. For De Moivre's theorem, show the angle multiplication and the resulting trigonometric form before converting to rectangular form.

Practice Questions

Multiple Choice (20 Questions)

Q1. In a right triangle, sin(θ) is defined as:

  • A. Adjacent/Hypotenuse
  • B. Opposite/Hypotenuse
  • C. Opposite/Adjacent
  • D. Hypotenuse/Opposite
Show Answer

Answer: B: SOH-CAH-TOA: Sin = Opposite/Hypotenuse. Cos = Adjacent/Hypotenuse. Tan = Opposite/Adjacent.

Q2. The value of sin(π/6) is:

  • A. √3/2
  • B. 1/2
  • C. √2/2
  • D. 1
Show Answer

Answer: B: π/6 = 30°. At 30°: sin(30°) = 1/2, cos(30°) = √3/2, tan(30°) = 1/√3. Memorize the 30-60-90 triangle ratios.

Q3. Which of the following is a Pythagorean identity?

  • A. sin(x) + cos(x) = 1
  • B. sin²(x) + cos²(x) = 1
  • C. tan(x) = sin(x) - cos(x)
  • D. sin²(x) - cos²(x) = 1
Show Answer

Answer: B: sin²(x) + cos²(x) = 1 is the fundamental Pythagorean identity, derived from the unit circle (x² + y² = 1). Related identities: 1 + tan²(x) = sec²(x); 1 + cot²(x) = csc²(x).

Q4. The reference angle for θ = 5π/4 is:

  • A. 5π/4
  • B. π/4
  • C. 3π/4
  • D. π
Show Answer

Answer: B: 5π/4 is in the third quadrant (between π and 3π/2). Reference angle = 5π/4 - π = π/4. Reference angles are always between 0 and π/2.

Q5. The Law of Sines states:

  • A. a² = b² + c² - 2bc cos(A)
  • B. sin(A)/a = sin(B)/b = sin(C)/c
  • C. a/sin(A) = 2R only
  • D. sin(A+B) = sin(A)cos(B) + cos(A)sin(B)
Show Answer

Answer: B: Law of Sines: in any triangle, sin(A)/a = sin(B)/b = sin(C)/c. Use when given AAS, ASA, or SSA (ambiguous case).

Q6. sec(θ) is the reciprocal of:

  • A. sin(θ)
  • B. cos(θ)
  • C. tan(θ)
  • D. cot(θ)
Show Answer

Answer: B: Reciprocal identities: sec(θ) = 1/cos(θ); csc(θ) = 1/sin(θ); cot(θ) = 1/tan(θ) = cos(θ)/sin(θ).

Q7. The angle addition formula for sin(A + B) is:

  • A. sin(A)sin(B) + cos(A)cos(B)
  • B. sin(A)cos(B) + cos(A)sin(B)
  • C. sin(A)cos(B) - cos(A)sin(B)
  • D. cos(A)cos(B) - sin(A)sin(B)
Show Answer

Answer: B: sin(A+B) = sin(A)cos(B) + cos(A)sin(B). Note: sin(A-B) = sin(A)cos(B) - cos(A)sin(B). These identities are foundational for deriving double-angle, half-angle, and product-to-sum formulas.

Q8. A polar coordinate (r, θ) converts to rectangular coordinates as:

  • A. x = r cos(θ), y = r sin(θ)
  • B. x = r sin(θ), y = r cos(θ)
  • C. x = tan(θ), y = r
  • D. x = r, y = θ
Show Answer

Answer: A: Polar to rectangular: x = r cos(θ), y = r sin(θ). Rectangular to polar: r = √(x²+y²), θ = arctan(y/x) (adjusted for quadrant).

Q9. The half-angle formula for sin(θ/2) is:

  • A. ±√((1+cos θ)/2)
  • B. ±√((1-cos θ)/2)
  • C. sin(θ)/2
  • D. cos(θ/2)
Show Answer

Answer: B: Half-angle formulas: sin(θ/2) = ±√((1-cosθ)/2); cos(θ/2) = ±√((1+cosθ)/2). The sign depends on the quadrant of θ/2.

Q10. The graph of y = cos(x) has period:

  • A. π
  • B. 2π
  • C. π/2
  • D. 4π
Show Answer

Answer: B: The cosine function has period 2π: cos(x + 2π) = cos(x) for all x. Same period as sine. Tangent has period π. For y = cos(Bx), period = 2π/|B|.

Q11. Which quadrant has sin > 0 and cos < 0?

  • A. Quadrant I
  • B. Quadrant II
  • C. Quadrant III
  • D. Quadrant IV
Show Answer

Answer: B: Unit circle quadrant signs: QI: all positive. QII: sin > 0, cos < 0. QIII: sin < 0, cos < 0. QIV: sin < 0, cos > 0. Mnemonic: All Students Take Calculus (all, sin, tan, cos positive in QI, II, III, IV respectively).

Q12. The inverse function arcsin(x) has domain:

  • A. All real numbers
  • B. [-1, 1]
  • C. [0, π]
  • D. (-π/2, π/2)
Show Answer

Answer: B: arcsin(x) = sin⁻¹(x) has domain [-1, 1] (the range of sine) and range [-π/2, π/2] (the restricted domain of sine that makes it invertible).

Q13. To solve 2cos(x) - 1 = 0 on [0, 2π):

  • A. x = π/6
  • B. x = π/3 and x = 5π/3
  • C. x = π/4 and x = 7π/4
  • D. x = π/2
Show Answer

Answer: B: 2cos(x) = 1 → cos(x) = 1/2. cos(x) = 1/2 at x = π/3 (QI) and x = 5π/3 (QIV). These are the two angles in [0, 2π) where cosine equals 1/2.

Q14. The product-to-sum formula converts sin(A)cos(B) to:

  • A. (1/2)[sin(A+B) + sin(A-B)]
  • B. sin(A+B) + sin(A-B)
  • C. (1/2)[cos(A-B) - cos(A+B)]
  • D. sin(AB)
Show Answer

Answer: A: Product-to-sum: sin(A)cos(B) = (1/2)[sin(A+B) + sin(A-B)]. These formulas convert products of trig functions to sums, useful in calculus (integration) and signal processing.

Q15. De Moivre's Theorem states that [r(cos θ + i sin θ)]ⁿ =

  • A. r(cos nθ + i sin nθ)
  • B. rⁿ(cos nθ + i sin nθ)
  • C. rⁿ(cos θ + i sin θ)
  • D. n | r(cos θ + i sin θ)
Show Answer

Answer: B: De Moivre's Theorem: [r cis θ]ⁿ = rⁿ cis(nθ) = rⁿ(cos(nθ) + i sin(nθ)). Powerful for computing powers and roots of complex numbers in polar form.

Q16. The area of a triangle with sides a, b and included angle C is:

  • A. (1/2)ab
  • B. (1/2)ab sin(C)
  • C. ab cos(C)
  • D. (1/2)ab cos(C)
Show Answer

Answer: B: Area = (1/2)ab sin(C). When the included angle between two known sides is given, this formula computes area without needing the altitude. For C = 90°: sin(90°) = 1, giving the familiar Area = (1/2)ab.

Q17. tan(π) equals:

  • A. Undefined
  • B. 0
  • C. 1
  • D. -1
Show Answer

Answer: B: tan(π) = sin(π)/cos(π) = 0/(-1) = 0. Tangent is zero whenever sine is zero (at multiples of π). tan(π/2) is undefined (cos(π/2) = 0, division by zero).

Q18. The equation r = 3 in polar coordinates represents:

  • A. A horizontal line
  • B. A circle of radius 3 centered at the origin
  • C. A vertical line at x = 3
  • D. A parabola
Show Answer

Answer: B: In polar coordinates, r = constant represents a circle centered at the origin with radius equal to the constant. r = 3 → all points exactly 3 units from the origin → circle of radius 3.

Q19. The double angle formula cos(2θ) = 1 - 2sin²(θ) is useful for:

  • A. Finding the sine of double angles
  • B. Expressing cos(2θ) in terms of sine only, useful for integration and solving equations
  • C. Finding the period of cosine
  • D. Proving the Pythagorean theorem
Show Answer

Answer: B: This form of the double-angle identity (cos(2θ) = 1 - 2sin²θ) comes from substituting sin²θ for (1-cos²θ)/... It's particularly useful in calculus for integrating sin²(x) by rewriting as (1 - cos(2x))/2.

Q20. The general solution to sin(x) = 1/2 is:

  • A. x = π/6
  • B. x = π/6 + 2πk or x = 5π/6 + 2πk, where k is any integer
  • C. x = π/6 + πk
  • D. x = 30° only
Show Answer

Answer: B: sin(x) = 1/2 has solutions at x = π/6 (QI) and x = 5π/6 (QII) within [0, 2π). Adding 2πk accounts for all coterminal angles. General solution: x = π/6 + 2πk or x = π - π/6 + 2πk = 5π/6 + 2πk.

A surveyor stands at point A and sights a building at point B at an angle of elevation of 32°. She then walks 50 meters closer to the building to point C and measures the angle of elevation to be 48°. (a) Draw and label a diagram for this situation. (b) Use the Law of Sines to find the distance CB (horizontal distance from C to the base of the building). (c) Find the height of the building.
View Model Answer
(a) Diagram: Points A and C are on level ground, with C between A and the building base D. B is the top of the building. Angle of elevation from A to B = 32°. Angle of elevation from C to B = 48°. AC = 50 m. The exterior angle at C in triangle ABC (angle ACB) = 180° - 48° = 132°. (b) Using triangle ABC (not the right triangles). Angle at A = 32°. Angle at B in triangle ABC = 180° - 32° - 132° = 16°. Angle at C = 132°. By Law of Sines: AB/sin(132°) = AC/sin(16°) → AB = 50 | sin(132°)/sin(16°) = 50(0.7431)/(0.2756) = 50(2.696) = 134.8 m. Now in right triangle ACB... Actually, using right triangle at D: CB/AB... Let me use right triangle from C. In right triangle CDB (B = top, D = base below B): CD = CB = horizontal distance = CB. angle at C = 48°. CB = CD (horizontal). Height h = CD | tan(48°). But we need CB first from Law of Sines: CB/sin(A) = AC/sin(B in ABC) → CB/sin(32°) = 50/sin(16°) → CB = 50 | sin(32°)/sin(16°) = 50(0.5299)/(0.2756) = 96.1 m. (c) Height: From right triangle CDB: tan(48°) = h/CB → h = CB | tan(48°) = 96.1 × 1.1106 = 106.7 m. The building is approximately 106.7 meters tall.

Free Response 2 (Free Response)

Prove the identity: (tan x + cot x) = (1)/(sin x cos x) Then use the identity to simplify: 1/(tan x + cot x)
View Model Answer
PROOF: Start with the left side. tan x + cot x = sin x/cos x + cos x/sin x. Find common denominator (sin x cos x): = sin²x/(sin x cos x) + cos²x/(sin x cos x) = (sin²x + cos²x)/(sin x cos x). Apply Pythagorean identity (sin²x + cos²x = 1): = 1/(sin x cos x). Therefore: tan x + cot x = 1/(sin x cos x). ■ APPLICATION: Simplify 1/(tan x + cot x). Using the proven identity: tan x + cot x = 1/(sin x cos x). Therefore: 1/(tan x + cot x) = 1/[1/(sin x cos x)] = sin x cos x. Alternatively, using the double angle identity: sin x cos x = (1/2)sin(2x). So: 1/(tan x + cot x) = sin x cos x = (1/2)sin(2x).

Free Response 3 (Free Response)

(a) Convert the complex number z = 1 + i√3 to polar form r(cos θ + i sin θ). (b) Use De Moivre's Theorem to compute z⁶. (c) Find all fourth roots of 16, expressing them in polar and rectangular form.
View Model Answer
(a) Polar form of z = 1 + i√3: r = √(1² + (√3)²) = √(1+3) = √4 = 2. θ = arctan(√3/1) = arctan(√3) = π/3 (first quadrant). Polar form: z = 2(cos(π/3) + i sin(π/3)) = 2 cis(π/3). (b) z⁶ by De Moivre's Theorem: z⁶ = [2 cis(π/3)]⁶ = 2⁶ cis(6 | π/3) = 64 cis(2π) = 64(cos(2π) + i sin(2π)) = 64(1 + 0i) = 64. So z⁶ = 64 (a real number, which makes sense since z = 2e^(iπ/3) and z⁶ = 2⁶e^(i2π) = 64). c) Fourth roots of 16: We need w such that w⁴ = 16. Write 16 in polar form: 16 = 16 cis(0) = 16 cis(2πk). Fourth roots: w_k = 16^(1/4) cis((0 + 2πk)/4) = 2 cis(πk/2) for k = 0, 1, 2, 3. w₀ = 2 cis(0) = 2(1 + 0i) = 2. w₁ = 2 cis(π/2) = 2(0 + i) = 2i. w₂ = 2 cis(π) = 2(-1 + 0i) = -2. w₃ = 2 cis(3π/2) = 2(0 - i) = -2i. The four fourth roots of 16 are: 2, 2i, -2, -2i. Verify: 2⁴ = 16 ✓; (2i)⁴ = 16i⁴ = 16(1) = 16 ✓.
