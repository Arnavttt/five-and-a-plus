How to Get a 5 on This Exam

📊 What the Exam Tests Most

AP Precalculus covers polynomial, rational, exponential, logarithmic, trigonometric, and sinusoidal functions deeply, along with function transformations, inverse functions, and polar/parametric coordinates. The exam emphasizes function analysis identifying key features from equations and graphs and mathematical modeling. About 40% of the exam tests trigonometry and its applications.

⚠️ Where Students Lose Points

Students confuse domain restrictions with range restrictions. Students lose points by describing graph transformations in the wrong order (horizontal and vertical transformations don't commute for some operations). In trigonometry, students confuse the period formula the period of y = sin(bx) is 2π/b, not 2πb. Amplitude changes affect vertical stretch, not period.

🎯 What Separates a 3 from a 5

A 3 student applies formulas correctly. A 5 student can reason backwards from a graph or data set to determine the appropriate function model, identify whether a function is periodic and with what parameters, and explain what each parameter means in context not just compute it.

📅 Final 2 to 3 Weeks Strategy

Master the unit circle know exact values for sin, cos, tan at 0, π/6, π/4, π/3, π/2, and their reflections in all quadrants. Practice identifying transformations from equations: y = af(b(x−h)) + k. Review logarithm laws and change of base. Practice fitting sinusoidal models to data. Do past FRQs on function composition and inverse functions.

Exam-Day Skills

  • Transformation order: For y = af(b(x−h)) + k: horizontal shift h (opposite sign), horizontal scale 1/b, vertical scale a, vertical shift k. Apply horizontal transformations before vertical when graphing.
  • Trig identities to know: Pythagorean (sin²θ + cos²θ = 1), sum/difference formulas, double-angle formulas (sin 2θ = 2 sinθ cosθ, cos 2θ = cos²θ − sin²θ). Don't memorize all identities know how to derive them.
  • Sinusoidal modeling: y = A sin(2π/T, (x − h)) + k where A = amplitude, T = period, h = horizontal shift (phase), k = midline. Given a graph, identify max and min to find A = (max−min)/2 and k = (max+min)/2.
  • Logarithm rules: log(ab) = log a + log b; log(a/b) = log a − log b; log(a^n) = n log a. Change of base: log_b(a) = ln(a)/ln(b). Know when to apply each.
  • MCQ function analysis: When asked about domain, set denominators ≠ 0, arguments of logarithms > 0, and arguments of square roots ≥ 0. Combine restrictions using intersection.

📋 How FRQ Scoring Works

Section I (50%): 40 MCQs in 80 min (28 without calculator, 12 with calculator). Section II (50%): 4 FRQs in 40 min (2 without calculator, 2 with calculator).

FRQ structure: Each FRQ has 3 to 4 parts testing function analysis skills. Parts typically ask you to: identify function properties (domain, range, zeros, asymptotes), describe transformations, evaluate function values or inverses, model real-world scenarios with functions, or analyze rates of change.

Scoring principle: Each part of a FRQ is scored independently (1 to 2 pts per part). Show your algebraic work: numerical answers without supporting algebra usually earn 0 pts for that part even if the answer is correct.

Function analysis: When asked to 'describe how the graph of g relates to f,' identify each transformation parameter (vertical/horizontal shift, stretch/compression, reflection) and state its effect precisely. Vague answers ('the graph moves') earn 0 pts.

Modeling questions: When asked to write a function model, identify the function type (sinusoidal, exponential, linear), determine all parameters from given information, write the function with all values substituted, and verify with a data point.

Practice Questions

Multiple Choice (20 Questions)

Q1. The vertex form of a quadratic function f(x) = a(x-h)² + k tells you:

  • A. The x-intercepts of the parabola
  • B. The vertex is at (h, k) and the parabola opens up if a > 0, down if a < 0
  • C. The y-intercept is (0, k)
  • D. The axis of symmetry is x = k
Show Answer

Answer: B: Vertex form f(x) = a(x-h)² + k: vertex is (h, k); a > 0 → opens upward (minimum at vertex); a < 0 → opens downward (maximum at vertex); axis of symmetry x = h.

Q2. The period of y = A sin(Bx + C) + D is:

  • A. 2π/A
  • B. 2π/|B|
  • C. B/(2π)
  • D. 2πB
Show Answer

Answer: B: For y = A sin(Bx + C) + D: amplitude = |A|, period = 2π/|B|, phase shift = -C/B, vertical shift = D. The period of the basic sine function is 2π; stretching/compressing the x-axis by factor |B| changes the period.

Q3. A function f is even if:

  • A. f(-x) = -f(x) for all x in the domain
  • B. f(-x) = f(x) for all x in the domain (symmetric about the y-axis)
  • C. f has an inverse function
  • D. f(0) = 0
Show Answer

Answer: B: Even functions: f(-x) = f(x) symmetric about the y-axis. Examples: f(x) = x², cos(x). Odd functions: f(-x) = -f(x) symmetric about the origin. Examples: f(x) = x³, sin(x).

Q4. The inverse function f⁻¹ exists if and only if f is:

  • A. A polynomial function
  • B. A one-to-one function (passes the horizontal line test)
  • C. Continuous on its domain
  • D. An odd function
Show Answer

Answer: B: For f⁻¹ to be a function, f must be one-to-one: each output corresponds to exactly one input. Graphically, f must pass the horizontal line test. We can restrict the domain of non-one-to-one functions (like f(x)=x²) to create an invertible piece.

Q5. The Fundamental Theorem of Algebra states that a polynomial of degree n:

  • A. Has exactly n positive real roots
  • B. Has exactly n roots (counting multiplicity) in the complex number system
  • C. Has at most n-1 local extrema
  • D. Can be factored into n linear real factors
Show Answer

Answer: B: Every polynomial of degree n ≥ 1 with complex coefficients has exactly n complex roots, counting multiplicity. This doesn't guarantee real roots x² + 1 has two complex roots (i and -i) but no real roots.

Q6. The exponential function f(x) = e^x is significant because:

  • A. It is its own derivative and integral (d/dx[e^x] = e^x)
  • B. It represents the only function where the growth rate equals the current value
  • C. Both A and B are true
  • D. Neither A nor B is true
Show Answer

Answer: C: The defining property of e^x: it is the unique function (up to a constant) that equals its own derivative. This means growth rate = current value, making it the natural model for continuously compounding growth, radioactive decay, and population dynamics.

Q7. log_b(xy) equals:

  • A. log_b(x) + log_b(y)
  • B. log_b(x) × log_b(y)
  • C. log_b(x) / log_b(y)
  • D. log_b(x+y)
Show Answer

Answer: A: Logarithm product rule: log_b(xy) = log_b(x) + log_b(y). This transforms multiplicative relationships into additive ones the reason logarithms were invented for computation.

Q8. The sum of a finite geometric series a + ar + ar² + ... + arⁿ⁻¹ equals:

  • A. a(1-rⁿ)
  • B. a(1-rⁿ)/(1-r) for r ≠ 1
  • C. arⁿ
  • D. na(1+r)/2
Show Answer

Answer: B: Finite geometric series sum: S_n = a(1-rⁿ)/(1-r) for r ≠ 1. This formula applies when each term is the previous term multiplied by constant ratio r.

Q9. Which of the following is equivalent to cos(2θ)?

  • A. 2 cos(θ)
  • B. cos²(θ) - sin²(θ)
  • C. 2 sin(θ)cos(θ)
  • D. 1 - cos²(θ)
Show Answer

Answer: B: Double-angle identity: cos(2θ) = cos²θ - sin²θ = 2cos²θ - 1 = 1 - 2sin²θ. Also, sin(2θ) = 2sinθcosθ. These are derived from the angle addition formulas.

Q10. For a rational function f(x) = p(x)/q(x), a vertical asymptote occurs where:

  • A. p(x) = 0
  • B. q(x) = 0 (and p(x) ≠ 0 at that point)
  • C. Both p(x) and q(x) equal 0
  • D. The degree of p exceeds the degree of q
Show Answer

Answer: B: Vertical asymptotes occur at values of x where the denominator q(x) = 0 but numerator p(x) ≠ 0. If both are zero, there may be a hole (removable discontinuity) rather than an asymptote.

Q11. The Law of Cosines states that in a triangle with sides a, b, c and angle C opposite side c:

  • A. c = a + b - 2ab cos(C)
  • B. c² = a² + b² - 2ab cos(C)
  • C. sin(C)/c = sin(A)/a
  • D. c² = a² + b² + 2ab cos(C)
Show Answer

Answer: B: Law of Cosines: c² = a² + b² - 2ab cos(C). Generalizes the Pythagorean theorem (when C = 90°, cos(90°) = 0, giving c² = a² + b²). Use when given SAS or SSS.

Q12. A polynomial's end behavior is determined by:

  • A. Its y-intercept
  • B. Its leading term (coefficient and degree)
  • C. All of its terms equally
  • D. Its number of real roots
Show Answer

Answer: B: End behavior is determined entirely by the leading term axⁿ: as x→±∞, the leading term dominates. Even degree: both ends go same direction. Odd degree: ends go opposite directions. Positive leading coefficient: right end goes up.

Q13. The unit circle definition of sin(θ) is:

  • A. Opposite/hypotenuse in a right triangle
  • B. The y-coordinate of the point where the terminal side of angle θ intersects the unit circle
  • C. Adjacent/hypotenuse in a right triangle
  • D. The x-coordinate on the unit circle
Show Answer

Answer: B: Unit circle: cos(θ) = x-coordinate, sin(θ) = y-coordinate of the point on the unit circle at angle θ from positive x-axis. This definition extends trig functions beyond right triangles to all real angles.

Q14. If f(x) = 2x + 3, then f⁻¹(x) equals:

  • A. 2x - 3
  • B. (x - 3)/2
  • C. 1/(2x + 3)
  • D. x/2 + 3
Show Answer

Answer: B: To find f⁻¹: replace f(x) with y → y = 2x + 3, swap x and y → x = 2y + 3, solve for y → y = (x-3)/2. So f⁻¹(x) = (x-3)/2. Verify: f(f⁻¹(x)) = 2, (x-3)/2 + 3 = x - 3 + 3 = x. ✓

Q15. The amplitude of y = -3 sin(2x) is:

  • A. −3
  • B. 3
  • C. 2
  • D. 6
Show Answer

Answer: B: Amplitude = |A| = |-3| = 3. Amplitude is always non-negative it represents the maximum displacement from the midline. The negative sign reflects the graph over the x-axis but doesn't change amplitude.

Q16. A horizontal asymptote of a rational function f(x) = p(x)/q(x) exists when:

  • A. p(x) and q(x) have common factors
  • B. The degree of p(x) ≤ degree of q(x), giving a horizontal asymptote at y = 0 or y = leading coefficient ratio
  • C. The function has a hole
  • D. The degree of p exceeds the degree of q by exactly 2
Show Answer

Answer: B: Horizontal asymptotes: if deg(p) < deg(q): y = 0; if deg(p) = deg(q): y = leading coefficient of p / leading coefficient of q; if deg(p) > deg(q): no horizontal asymptote (oblique asymptote or none).

Q17. The composition (f ∘ g)(x) means:

  • A. f(x) + g(x)
  • B. f(g(x)) apply g first, then apply f to the result
  • C. f(x) × g(x)
  • D. g(f(x))
Show Answer

Answer: B: Function composition (f ∘ g)(x) = f(g(x)): first apply g to x, then apply f to the result. Order matters: f ∘ g ≠ g ∘ f in general.

Q18. For an arithmetic sequence with first term a₁ and common difference d, the nth term is:

  • A. a₁ + nd
  • B. a₁ + (n-1)d
  • C. a₁ × dⁿ
  • D. a₁ × d^(n-1)
Show Answer

Answer: B: Arithmetic sequence: a_n = a₁ + (n-1)d. The nth term equals the first term plus (n-1) increments of the common difference d.

Q19. The discriminant b² - 4ac of a quadratic ax² + bx + c = 0 tells you:

  • A. The vertex of the parabola
  • B. Whether the quadratic has 2 real roots (> 0), 1 repeated real root (= 0), or 2 complex roots (< 0)
  • C. The product of the roots
  • D. The y-intercept
Show Answer

Answer: B: Discriminant D = b² - 4ac: D > 0 → two distinct real roots; D = 0 → one repeated real root (tangent to x-axis); D < 0 → two complex conjugate roots (graph doesn't cross x-axis).

Q20. The reference angle for 240° is:

  • A. 240°
  • B. 60°
  • C. 120°
  • D. 30°
Show Answer

Answer: B: Reference angle: the acute angle between the terminal side of the given angle and the nearest x-axis. 240° is in the third quadrant; 240° - 180° = 60°. The reference angle is always positive and between 0° and 90°.

Free Response Questions

FRQ 1 (FRQ)

Let f(x) = x³ - 4x and g(x) = x + 2. (a) Find (f ∘ g)(x) and simplify completely. (b) Find all zeros of f(x) and describe the multiplicity of each. (c) Sketch a graph of f(x) showing key features: zeros, end behavior, and any local extrema.
View Model Answer
(a) (f ∘ g)(x) = f(g(x)) = f(x+2) = (x+2)³ - 4(x+2). Expand: (x+2)³ = x³ + 6x² + 12x + 8. So (f∘g)(x) = x³ + 6x² + 12x + 8 - 4x - 8 = x³ + 6x² + 8x. (b) Zeros of f(x) = x³ - 4x = x(x² - 4) = x(x-2)(x+2). Zeros: x = 0, x = 2, x = -2. Each zero has multiplicity 1 (each factor appears once). Multiplicity 1 zeros: the graph crosses the x-axis at each zero rather than bouncing off it. (c) Graph description: End behavior: degree 3, positive leading coefficient → as x→-∞, f→-∞; as x→+∞, f→+∞. Zeros (x-intercepts): x = -2, 0, 2 (all crossing). Local extrema (from f'(x) = 3x² - 4 = 0 → x = ±√(4/3) ≈ ±1.15): local maximum at x ≈ -1.15: f(-1.15) ≈ 3.08; local minimum at x ≈ 1.15: f(1.15) ≈ -3.08. y-intercept: f(0) = 0.

FRQ 2 (FRQ)

A bacteria population starts at 500 and doubles every 3 hours. (a) Write an exponential function P(t) representing the population after t hours. (b) Find the population after 12 hours. (c) How long will it take for the population to reach 10,000? Give an exact answer and an approximation.
View Model Answer
(a) Exponential growth with doubling time 3 hours: P(t) = P₀, 2^(t/3) = 500, 2^(t/3). Alternatively, using base e: P(t) = 500e^(kt) where k = ln(2)/3 ≈ 0.231. (b) At t = 12 hours: P(12) = 500, 2^(12/3) = 500, 2⁴ = 500, 16 = 8,000 bacteria. (c) Solve 500, 2^(t/3) = 10,000: 2^(t/3) = 20. Take log base 2: t/3 = log₂(20) = ln(20)/ln(2). t = 3, ln(20)/ln(2) = 3 × (2.996/0.693) ≈ 3 × 4.322 = 12.97 hours. Exact answer: t = 3log₂(20) = 3ln(20)/ln(2) hours. Approximately 12.97 hours (just under 13 hours).

FRQ 3 (FRQ)

a) Define what it means for a function to be one-to-one and explain why f(x) = x² is NOT one-to-one on all real numbers. b) Restrict the domain of f(x) = x² so that f is invertible, and find the inverse function. c) Verify that f(f⁻¹(x)) = x for your restricted function.
View Model Answer
a) A function is one-to-one (injective) if each output value corresponds to exactly one input: whenever f(a) = f(b), it follows that a = b. Graphically, the function passes the horizontal line test no horizontal line intersects the graph more than once. f(x) = x² is NOT one-to-one on all real numbers because f(2) = 4 = f(-2): the same output (4) is produced by two different inputs (2 and -2). The horizontal line y = 4 intersects the parabola at two points. b) Restricted domain: restrict f to [0, ∞) (the right half of the parabola). On this domain, f(x) = x² is one-to-one (strictly increasing). To find the inverse: y = x² → x = √y (taking positive root because x ≥ 0) → f⁻¹(x) = √x, domain [0, ∞). The inverse is the square root function. c) Verification: f(f⁻¹(x)) = f(√x) = (√x)² = x, for x ≥ 0. ✓ Also check: f⁻¹(f(x)) = √(x²) = |x| = x, for x ≥ 0 (since we restricted to non-negative x). ✓ This confirms f⁻¹(x) = √x is the correct inverse on the restricted domain.
