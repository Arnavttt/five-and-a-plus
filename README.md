# Five & A+

Published static site for **Five & A+** — a free AP® and college review study platform.

Live: https://arnavttt.github.io/five-and-a-plus/

This repository contains only the built, public-facing site (HTML/CSS/JS) so it can
be served by GitHub Pages for free. The source (content generators, the Flutter app,
build scripts) lives in a separate private repository.
