Functions, Domain, and Range

A function assigns exactly one output to each input. The domain is the set of all valid inputs (x-values); the range is the set of all outputs (y-values). Common domain restrictions: denominators ≠ 0; radicands of even roots ≥ 0. The vertical line test: if any vertical line crosses a graph more than once, the relation is NOT a function.

Common misconception: Students confuse "not a function" with "has no value": a graph can still have y-values at every x but fail the vertical line test (e.g., a circle).

How it can be tested: Identify functions using the vertical line test; determine domain and range; state domain restrictions for rational/radical functions.

Transformations and Inverse Functions

Graph transformations: f(x)+k shifts up k; f(x+h) shifts left h; -f(x) reflects over x-axis; f(-x) reflects over y-axis; af(x) vertical stretch (a>1) or compression (0

Common misconception: Students confuse horizontal shift direction: f(x+3) shifts LEFT 3 (not right), because x+3=0 when x=-3.

How it can be tested: Apply transformations to sketch graphs; find inverse functions algebraically; use the horizontal line test.

Key Vocabulary
  • domain: The set of all valid input (x) values for a function
  • range: The set of all output (y) values produced by a function
  • vertical line test: A graph represents a function if and only if no vertical line crosses the graph more than once
  • horizontal line test: A function is one-to-one (has an inverse function) if and only if no horizontal line crosses the graph more than once
  • piecewise function: A function defined by different formulas on different intervals of the domain
  • even function: f(-x) = f(x): symmetric about the y-axis; odd function: f(-x) = -f(x), symmetric about the origin
Objectives
  • Apply the vertical line test to identify functions
  • State the domain and range of common functions
  • Apply transformations and sketch the resulting graph
  • Find inverse functions algebraically
How this can be tested
  • Find the domain of f(x) = √(x-3) / (x-5)
  • If f(x) = 2x+1, find f^(-1)(x) and verify f(f^(-1)(x)) = x
Practice before moving on
  • What does the horizontal line test tell you about a function's inverse?
Key Formulas
  • Composition: \( (f\circ g)(x)=f(g(x)) \)
  • Inverse: \( f(f^{-1}(x))=x;\quad f^{-1}(f(x))=x \)
  • Transformations: \( y=a\,f(b(x-h))+k \)

Q1
The domain of f(x) = 1/(x^2 - 9) is
  • A) all real numbers
  • B) x > 0 only
  • C) x ≠ 0
  • D) all real numbers except x = ±3 (where the denominator is zero)
D is correct. all real numbers except x = ±3 (where the denominator is zero)
Q2
The graph of f(x) + 3 is the graph of f(x) shifted
  • A) up 3 units (vertical shift)
  • B) right 3 units
  • C) left 3 units
  • D) down 3 units
A is correct. up 3 units (vertical shift)
Q3
The graph of f(x - 2) is the graph of f(x) shifted
  • A) left 2 units
  • B) up 2 units
  • C) down 2 units
  • D) right 2 units: replace x with x-2 means the graph moves in the positive x direction
D is correct. right 2 units: replace x with x-2 means the graph moves in the positive x direction
Q4
The inverse of f(x) = 3x - 6 is
  • A) f^(-1)(x) = 3x + 6
  • B) f^(-1)(x) = 1/(3x-6)
  • C) f^(-1)(x) = -3x + 6
  • D) f^(-1)(x) = (x + 6)/3: swap x and y: x = 3y-6, solve for y
D is correct. f^(-1)(x) = (x + 6)/3: swap x and y: x = 3y-6, solve for y
Q5
(f ∘ g)(x) where f(x) = x^2 and g(x) = x+1 equals
  • A) (x^2)+1
  • B) (x+1)^2: apply g first (x+1), then apply f (square it)
  • C) x^2 + 1
  • D) x^2(x+1)
B is correct. (x+1)^2: apply g first (x+1), then apply f (square it)
Exit ticket
  • ('A relation is a function only if', 'every input (x-value) maps to exactly one output: no x-value can pair with two different y-values', ['every output maps to exactly one input', 'the graph is a smooth curve without gaps', 'the domain includes all real numbers'])
  • ('The function f(x) = |x| has the range', '[0, ∞): absolute value outputs are always non-negative', ['all real numbers (-∞, ∞)', '(-∞, 0]', '(0, ∞)'])
  • ('Reflecting f(x) over the y-axis produces', 'f(-x): replace x with -x to reflect over the y-axis', ['-f(x) (reflection over x-axis)', 'f(x) + k (vertical shift)', 'f(x - k) (horizontal shift)'])
  • ('A function is one-to-one if', 'every output corresponds to exactly one input: it passes both the vertical AND horizontal line tests', ['it passes only the vertical line test', 'its domain is all real numbers', 'it is a polynomial function'])
  • ('The notation f^(-1)(x) means', 'the inverse function of f: the function that undoes f; NOT the reciprocal 1/f(x)', ['1/f(x): the reciprocal of f', 'the derivative of f', 'f applied twice'])
  • ('The domain of f(x) = √(2x - 8) is', 'x ≥ 4: set 2x - 8 ≥ 0 and solve: x ≥ 4', ['x ≥ 0', 'x ≥ 8', 'all real numbers'])
  • ('A vertical stretch by factor 3 transforms f(x) to', '3f(x): multiply every y-value by 3, making the graph taller', ['f(3x) (horizontal compression)', 'f(x/3) (horizontal stretch)', 'f(x) + 3 (vertical shift up)'])
  • ('If f(2) = 7, then f^(-1)(7) equals', '2: the inverse function reverses the mapping: if f maps 2 to 7, then f^(-1) maps 7 to 2', ['1/7', '7/2', '14'])
  • ('An even function satisfies', 'f(-x) = f(x): its graph is symmetric about the y-axis (e.g., f(x) = x^2)', ['f(-x) = -f(x) (that is an odd function)', 'f(x) = f(x+2) (periodic)', 'f(x) > 0 for all x'])
  • ('The range of f(x) = -x^2 + 4 is', '(-∞, 4]: the parabola opens downward with vertex at (0, 4), so outputs are at most 4', ['[4, ∞)', 'all real numbers', '[-4, 4]'])
⚡ Common Mistakes & Exam Tips
  • Forgetting that pH + pOH = 14 only at 25°C. At other temperatures, Kw changes and this relationship shifts.
  • Misidentifying buffer regions in a titration curve buffer region is where pH changes slowly, halfway to equivalence point, where pH = pKa.
  • Exam tip: For weak acid/strong base titrations, at the equivalence point, the solution is BASIC (conjugate base hydrolyzes). For strong acid/strong base, it's neutral.

🎯 Exam Strategy & Test-Taking Tips
  • Show algebraic steps: write each transformation on its own line; skip steps lose points.
  • Check your answer: substitute back into the original equation to verify.
  • Factoring vs. quadratic formula: try factoring first; if coefficients are large or irrational, use the formula.
  • Sign errors: the most common algebra mistake; double-check negatives when distributing or dividing.
  • Simplify completely: reduce fractions, combine like terms, rationalize denominators.
